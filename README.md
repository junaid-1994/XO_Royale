# XO Royale

A royal-themed Tic Tac Toe game built with React to showcase React fundamentals, state management, and responsive UI design.

## Overview

XO Royale is a beginner-friendly React project designed to practice core front-end skills while building a fun and polished game. The initial version keeps the logic in a single component to focus on React state, event handling, and UI updates.

This project will evolve over time with gradual improvements using React fundamentals, component separation, and cleaner application structure.

## Features

- Royal-themed game interface
- Title and logo section
- Player name inputs with edit mode
- 3x3 Tic Tac Toe board
- Turn tracking
- Move log panel
- Winner popup with Rematch reset
- Responsive layout for mobile and desktop

## Tech Stack

- React
- Vite
- CSS

## Project Goal

This project is intended to demonstrate:
- React component state
- Event-driven UI
- Conditional rendering
- Game logic implementation
- Responsive design
- Clean project structure for future enhancement
